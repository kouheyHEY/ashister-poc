# アシスター PoC

「学び」と「欲しいもの」を覚えて、毎日の小さな前進を支えるキャラクター型アシスタントの操作モックです。

## 試せること

- 3種類の日本語トレーニングと簡易フィードバック
- 欲しいものの追加、状態変更、削除
- 購入数と実現率の自動更新
- ブラウザ内への体験データ保存
- PC・スマートフォン向けのレスポンシブ表示

## ローカルで見る

依存パッケージはありません。`index.html` をブラウザで開くか、任意の静的ファイルサーバーでこのフォルダーを公開してください。

テストはNode.jsで実行できます。

```sh
node --test
```

## PoC上の制限

このモックは画面体験を検証するためのものです。フィードバックは端末内の簡易ロジックで生成しており、AIによる文章評価、ログイン、クラウド同期、通知などは実装していません。

「実現率」は `購入済み ÷（欲しい + 購入済み）` で計算し、保留・手放した項目は対象外です。
