# アシスター PoC

欲しいものを覚えて、ひとつずつ叶えるキャラクター型アシスタントの操作モックです。

## 試せること

- 欲しいものの追加、状態変更、削除
- 欲しい数、購入数、実現率の自動更新
- 優先度をもとにした「次に叶えたいもの」の表示
- 一覧のページ送りと左右スワイプ
- アシスターとの会話による追加・購入報告
- 会話からデータを変更する直前の確認
- 頻出操作を大きく、画面下部へ配置した片手操作
- ブラウザ内への体験データ保存
- 縦スクロールを使わないスマートフォン中心の操作
- PCではスマートフォン版を中央に表示

## ローカルで見る

依存パッケージはありません。`index.html`をブラウザで開くか、任意の静的ファイルサーバーでこのフォルダーを公開してください。

```sh
node --test
```

## PoC上の制限

ログイン、クラウド同期、通知、価格追跡、決済は実装していません。入力内容はブラウザ内にだけ保存されます。

「実現率」は `購入済み ÷（欲しい + 購入済み）` で計算し、保留・手放した項目は対象外です。
